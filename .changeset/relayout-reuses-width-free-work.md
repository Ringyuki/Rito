Laying a chapter out again at another size, as for every size of a window being dragged, now repeats only the work the size changes. A chapter keeps its styles while no `vw`/`vh` unit or `@media` query answers differently, and its formatting tree while its styles and images hold. A chapter is paginated from its line boxes alone and only the pages read are laid out with their text, and a paragraph that would break into the same lines at the new width keeps the lines it broke into. A line laid out without its text is read run by run instead of glyph by glyph. A paragraph keeps its shaped text; an image or inline block in it is sized again for the new width instead of the whole paragraph being shaped again, and its min- and max-content widths are measured once. A page's query artifact is built when the page is read and a chapter's search records when it is first searched. Finding the page the reader stays on reads each run's source start without copying its path, and finds the run's place in a long paragraph's source by binary search. The hits of the spread shown slice their text in one pass and are no longer hashed. A book-wide layout no longer evicts the chapter being read from the kept paragraphs. While a host holds the book (`holdBookLayout`), the spreads beside the one shown wait for it to be released.
